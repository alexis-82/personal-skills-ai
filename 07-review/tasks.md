# Lista delle Attività per la Code Review

## Attività
1. [ ] Recuperare diff del lavoro corrente
2. [ ] Rileggere `.claude/spec.md` (Goals, Non-Goals, criteri)
3. [ ] Analizzare correttezza
4. [ ] Analizzare edge case non coperti dai test
5. [ ] Analizzare sicurezza
6. [ ] Analizzare prestazioni
7. [ ] Analizzare leggibilità / manutenibilità
8. [ ] Scrivere `.claude/review.md` con findings numerati per severità
9. [ ] Suggerire fase successiva in base ai findings (implement / refactor / commit)
