# Piano di Code Review

## Obiettivo
Trovare problemi nel codice implementato prima del commit.

## Passaggi
1. Recuperare il diff del lavoro corrente
2. Rileggere Goals, Non-Goals e criteri di accettazione
3. Analizzare su 5 assi (correttezza, edge case, sicurezza, prestazioni, leggibilità)
4. Documentare findings con severità e locazione
