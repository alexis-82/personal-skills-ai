# Piano di Push

## Obiettivo
Pubblicare sul remote i commit già creati, senza riscrivere la storia

## Passaggi
1. Verificare che non ci siano modifiche non committate
2. Confrontare il branch locale con il remote
3. Mostrare i commit in uscita e chiedere conferma
4. Eseguire il push
5. Aprire la pull request, se richiesta
