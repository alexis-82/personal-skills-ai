# Lista delle Attività per il Push

## Attività
1. [ ] Controllare `git status` (niente modifiche non committate)
2. [ ] Verificare remote e upstream del branch corrente
3. [ ] `git fetch` e confronto avanti/indietro
4. [ ] Mostrare i commit in uscita e ottenere conferma
5. [ ] Push (`-u` se manca l'upstream)
6. [ ] PR con corpo da file, solo se richiesta
